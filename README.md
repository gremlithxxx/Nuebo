# Finanzas

App web de finanzas personales (HTML, CSS y JavaScript puro). Sin dependencias ni instalación.

Los datos se guardan en el navegador de cada persona (`localStorage`).

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub (público).
2. Sube todos los archivos a la raíz del repositorio, con `index.html` incluido.
3. Ve a **Settings → Pages**.
4. En **Source** elige **Deploy from a branch**, rama `main` y carpeta `/ (root)`. Guarda.
5. Espera uno o dos minutos. Tu app estará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.

## Correr en local

    python -m http.server 8000

Abre http://localhost:8000
